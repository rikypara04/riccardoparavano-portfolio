# Riccardo Paravano Portfolio
Professional portfolio built with Astro, TypeScript and custom CSS.
## Commands
- `npm run dev`
- `npm run check`
- `npm run build`
- `npm run validate`

## Public assets
The downloadable CV is stored at `public/cv/riccardo-paravano-cv.pdf`. Replace that file after updating the LaTeX CV, then validate and commit the new PDF.
